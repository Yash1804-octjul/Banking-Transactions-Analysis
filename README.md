# Banking Transactions Analysis Dashboard

## Project Overview

This project focuses on analyzing banking transactions and customer activity using **SQL Server** and **Microsoft Power BI**.

The dashboard provides insights into transaction trends, customer demographics, banking activities, and account balances through interactive visualizations. It helps understand transaction patterns and explore banking data from multiple perspectives.

## Problem Statement

The objective of this project is to analyze banking transaction data to identify meaningful patterns and trends in customer banking activities.

The analysis focuses on understanding transaction behavior, comparing transaction trends, exploring customer demographics, and examining banking activities across different dimensions.

## Tools & Technologies

- **SQL Server:** Data querying and analysis.
- **Microsoft Power BI:** Data modeling, visualization, and dashboard development.
- **DAX:** Calculations and analytical measures (where applicable).
- **Power Query:** Data transformation (where applicable).

## Dashboard Features

The report consists of One interactive pages covering different aspects of banking analysis.

### 1. Banking Transaction Analysis

- Monthly transaction trends.
- Transaction analysis by type.
- Remaining balance analysis.
- Bank-wise transaction analysis.
- Interactive filtering capabilities.

### 2. Customer & Transaction Analysis

- Customer demographic analysis.
- Transaction distribution by gender.
- Device type analysis.
- City-wise transaction analysis.
- Bank Name Sent and Bank Name Received analysis.

## Key Areas of Analysis

- Transaction trends over time.
- Customer banking behavior.
- Transaction patterns across different categories.
- Bank-wise transaction activities.
- Customer demographics and device preferences.
- Account balance analysis.

## Interactive Features

- Dynamic slicers and filters.
